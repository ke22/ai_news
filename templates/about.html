About

An Agentic AI Practice

What is this?

AI News Monitor is an autonomous pipeline that searches for AI news every morning, synthesises the findings into a bilingual summary, and publishes it as a permanent static web page — with no human in the loop after initial setup.

The project demonstrates two things at once: agentic AI as a product (a news monitor that runs itself) and as a process (spec-driven development where the AI participates in every stage, from proposal to code).

Design principles

  • Zero server cost. Static HTML on GitHub Pages — no cloud compute, no database.
  • Append-only storage. Every run appends to summaries.md. Nothing is ever overwritten.
  • Agentic search. The model decides which queries to run each day, not a fixed list. Coverage adapts to what is actually happening.
  • Bilingual by design. English and Traditional Chinese sections are written independently, not translated from each other.

Technology stack

  • Python 3.12 · Google Gemini API (gemini-2.0-flash) · Tavily Search API
  • GitHub Actions (cron scheduling) · GitHub Pages (hosting)
  • Vanilla HTML/CSS — no framework, no build step
  • Spectra change management · Claude Code

Development process

This project was built using Spectra, a spec-driven workflow where AI participates in the entire development lifecycle. The human made architectural decisions; the AI wrote all proposals, designs, specs, and code.

  /spectra-discuss  →  understand the problem
  /spectra-propose  →  proposal + design + specs + tasks
  /spectra-apply    →  implementation
  /spectra-archive  →  snapshot and close

Is this "real" agentic AI?

For: The model genuinely decides which search queries to run each day. It is not given a fixed list. It decides when it has enough information and calls submit_report to end the loop. The outcome varies every run.

Against: The tool set is narrow (search + submit). There is no memory across runs, no self-correction, no planning across multiple days. The "autonomy" is bounded by a tight schema and a 10-call limit.

Verdict: it is a constrained agentic loop — genuinely adaptive within a well-defined task, but not open-ended agency. That is probably the right scope for a daily news digest.

這是什麼？

AI 新聞監測是一個每天早晨自動搜尋 AI 新聞、將結果整理成雙語摘要，並發布為永久靜態網頁的自主流程——初始設定完成後，全程無需人工介入。

這個專案同時展示了兩件事：AI 代理作為產品（一個能自我運行的新聞監測器），以及作為流程（一種規格驅動的開發方式，AI 參與從提案到程式碼的每個環節）。

設計原則

  • 零伺服器成本。 靜態 HTML 託管於 GitHub Pages——無雲端運算，無資料庫。
  • 只附加、不覆寫。 每次執行皆附加至 summaries.md，資料永不被覆蓋。
  • 自主搜尋。 模型每天自行決定搜尋查詢，而非固定清單，覆蓋範圍隨當日 AI 動態自動調整。
  • 雙語設計。 英文與繁體中文各自獨立撰寫，並非互相翻譯。

  • GitHub Actions（排程）· GitHub Pages（託管）
  • 純 HTML/CSS——無框架，無建置步驟
  • Spectra 變更管理 · Claude Code

開發流程

本專案使用 Spectra 建構，這是一種規格驅動的工作流程，AI 參與整個開發週期。人類負責架構決策，AI 撰寫所有提案、設計、規格與程式碼。

這是「真正的」AI 代理嗎？

支持方： 模型每天真正自行決定搜尋查詢，而非照著固定清單執行。它自行判斷何時蒐集了足夠資訊，並呼叫 submit_report 結束迴圈。每次執行的結果都不同。

反對方： 工具集很窄（搜尋 + 提交）。沒有跨次執行的記憶，沒有自我修正，沒有跨日規劃。「自主性」受到嚴格的結構定義與 10 次呼叫上限所約束。

結論：這是一個受限的代理迴圈——在明確定義的任務範圍內具有真正的適應性，但並非開放式的自主代理。對於每日新聞摘要來說，這可能是恰當的範疇。
